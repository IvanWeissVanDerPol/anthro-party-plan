# Travel Guide — San Lorenzo, Paraguay → Córdoba, Argentina

## Overview

Distance: ~940 km by road. Same timezone (UTC-3).

## Option A: Bus (Cheapest)

| Detail | Info |
|---|---|
| **From** | Terminal de Ómnibus Asunción (30 min from San Lorenzo) |
| **To** | Terminal de Ómnibus Córdoba |
| **Companies** | Crucero del Norte (best), NSA + Sierras de Córdoba, 20 de Junio |
| **Duration** | 18-21 hours |
| **Price** | **$45-65/person one-way** → **$90-130/person RT** |
| **Seat types** | Semi-cama (reclines 140°, fine for sleeping) |
| **Total for 2** | **~$180-260 RT** |

### Bus tips

- Book Crucero del Norte semi-cama — best value
- Take the night bus (departs ~8pm → arrives next day ~2pm) — saves 1 night accommodation
- Bring: neck pillow, blanket (bus AC is freezing), snacks, yerba/tereré
- Bus has bathroom and stops every 4-5 hours for food
- San Lorenzo → Asunción terminal: colectivo ~$1-2, taxi ~$5

## Option B: Plane (Best Value)

| Detail | Info |
|---|---|
| **Route** | Silvio Pettirossi (ASU) → Pajas Blancas (COR) |
| **Airlines** | **JetSMART** or **Flybondi** (low-cost) |
| **Duration** | 5-7h (always 1 stop via Buenos Aires AEP) |
| **Price** | **$90-120/person one-way** |
| **Total for 2** | **~$180-240 RT** |

### Plane tips

- JetSMART is the cheapest — book NOW for best rates
- Cheapest months for ASU→COR: December-February (~$87 avg)
- October is peak season ($268 avg) — book early
- Direct flights NOT available — always connect in Buenos Aires
- Luggage: low-cost airlines charge extra for checked bags. Pack light (backpack only)

## Option C: Car (Not Recommended)

| Detail | Info |
|---|---|
| **Distance** | ~940 km actual driving |
| **Time** | 15-16 hours straight |
| **Route** | San Lorenzo → Encarnación border → Posadas → RN14 → Santa Fe → Córdoba |
| **Fuel** | ~$110 one-way (gas more expensive in PY, cheaper in ARG) |
| **Tolls** | ~$10-15 total |
| **Total one-way** | ~$120-130 |
| **Round trip** | ~$240-260 |
| **Borders** | PY-ARG at Encarnación/Posadas or Clorinda/Puerto Falcón |

For 2 people, the cost is similar to flying but takes 3x longer and you're exhausted.

## Border Crossing Notes

If driving or bussing:
- PY exit: quick passport stamp at Encarnación or Clorinda
- ARG entry: longer lines, may ask for return ticket and proof of funds
- No visa needed for Paraguayans or most nationalities entering Argentina
- Bus handles all border paperwork — you just show passport
